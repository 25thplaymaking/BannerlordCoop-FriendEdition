MINIMUM COMPONENTS NEEDED

PRIMARY RISKS
- The old binary may change its lifecycle shape or patch owner; exact fingerprint and reflection-shape checks fail closed.
- A rebellion command can touch several native collections; postconditions and normal Coop campaign replication are required before acceptance.
- R&D overlaps Friend Edition Separatism/Diplomacy rebellion ownership; the adapter owns only its own server behavior while the existing compatibility policy continues to suppress conflicting Diplomacy civil-war code.
